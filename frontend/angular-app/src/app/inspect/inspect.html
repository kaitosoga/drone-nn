What is an AI?

An AI like the one in this game is not a thinking brain. It does not understand the game, the drone, or the goal in the way a human does.

Instead, it is a system that has learned patterns from many examples. It has seen many situations (for example: positions, velocities, angles) and learned what actions worked well in those situations.

When the AI plays, it simply looks at the current situation (current velocity, checkpoint coordinates, etc...) and produces an output based on what it has learned before. It does not know why something works - it only knows that certain patterns are often linked to "good" outcomes.

What is an FFN?

The AI used here is a so-called feedforward network (FFN). You can think of it as a chain of simple steps that transform inputs into outputs.

It takes numbers as input (for example: velocity, position, angle, distance to the next checkpoint) and produces numbers as output (the thrusts of the drone).

Between input and output, the data passes through several layers. Each layer slightly changes and recombines the information before passing it on.

Specifically, each neuron (the round dots in the visualisation) becomes a combination of all the neuron activations (values of the dots of the layer to the left), but each previous input is weighed differently, which means different inputs are attribute more or less "importance".
This happens at each layer: it takes inputs, recombines each input value into new combinations, each of which become some new input to the next layer (neurons), and the only thing that changes is the layer size (amount of neurons in the layer).
In the end, the AI is just one large function that turns a situation (state variables as inputs) into different represetnations of data until, eventually, the representation is just two values - the thrust outputs that control the drone.

How does the AI make decisions?

Since each layer recombines its inputs with different weight, the function can learn very complex and non-linear patterns or correlations. What do the neurons represent?

So, when you look at the visualisation at the top, each dot (neuron) you see is a small unit that reacts to certain patterns in the input.

You can observe:
which neurons are active
how information flows through the layers
how the final decision is built step by step

A neuron becomes active when the pattern it is sensitive to is present. For example, one neuron might react to "high upward speed", while another reacts to "being close to a checkpoint".

But unlike human thinking, these meanings are not conceptual or easy to interpret. Each neuron usually responds to a mix of different things, but you can play around with the manual inputs, or observe them in a live game.

(This is also why the network is hard to interpret: information is spread out across many neurons instead of being stored in clear concepts, yet the AI can learn very useful patterns and eventually play the game).

What does training mean?

Before the AI can play well, it is trained on many examples.

It repeatedly sees situations and adjusts itself based on what leads to better outcomes. Over time, it becomes better at linking situations to useful actions.

Important: it does not learn rules like "always move towards the checkpoint". Instead, it learns that certain patterns are often followed by success, which was, in my training, defined as the negative distance to the next checkpoint.

This is called learning correlations: the AI recognises what tends to work, without understanding the underlying reason.

Why is this interesting?

Humans usually think in clear rules and causes: "I move left because the checkpoint is there".

The AI does something different. It combines many small signals and correlations into a decision, without forming clear reasoning.

This difference is what this project is about:
Understanding how human intuition and AI behaviour differ - and seeing it directly in action.
